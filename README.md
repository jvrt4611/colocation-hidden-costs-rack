## Colocation 到底是什么（以及它不是什么）

在 colocation 安排中，数据中心提供大楼，而您提供设备。您可以租用几个机架单元（1U 为 1.75 英寸的垂直空间）、一个完整的 42U 机柜、一个上锁的笼子或一个私人套间。该设施负责提供冗余电力、制冷、网络上行链路和物理访问控制。您保留硬件的所有权和控制权，Sharktech 自己将其定位为“保留所有权。获得基础设施。”。[S9]

这与租用专用服务器是不同的产品。使用专用服务器时，提供商拥有该机器；而在托管（colo）中，您购买的服务器仍然属于您，并且您需要支付其托管费用。这种区别完全决定了成本计算：托管服务的标价看起来很低，但只有在您已经拥有或计划购买硬件的情况下才有意义。如果您不拥有硬件，Sharktech 自己的 cloud 产品（套餐起价为 $39/月）是一个更便宜的起点，下文会对此进行说明。

这也是为什么公司在迁出 hyperscale cloud 时会选择托管：他们直接购买硬件，并在多年内以远低于等效云实例的成本运行它。代价是什么？硬件故障、备件和更新周期现在都是您的问题。

## FAQ

**托管比云便宜吗？**
对于在您拥有的硬件上进行稳定、可预测的工作负载，通常是的，在多年范围内差距很大。对于突发或短期的负载，云的灵活性胜出。托管还将硬件故障风险转移给您，而云不会。

**入门最低要求是什么？**
在 Sharktech，1–6U 档位中一台机架安装的服务器就足够了。您需要自己的服务器（带导轨）和运输计划。

**我需要住在数据中心附近吗？**
不需要。大多数托管客户从不亲自到访他们的机架；远程操作人员处理物理干预，您通过网络管理服务器。只有当您想要常规的物理访问或超低延迟互连时，邻近度才重要。

**有合同承诺吗？**
价格按月公布。机柜和自定义部署是根据各自条款单独报价的。

**我的硬件会得到什么保护？**
物理安全是标准的托管环境：监控、访问控制和消防系统，位于像设施列表中那些运营商级建筑中。正常运行时间保证涵盖的是 Sharktech 的网络，而非您的机器 —— 如果您的服务器出现故障，恢复是尽力而为的，系统管理默认是不包含的。将远程操作范围与您的团队提前列出，这样在您需要有人执行硬件更换时就不会产生意外。
